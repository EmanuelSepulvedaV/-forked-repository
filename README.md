# Proyecto-Final

Mis objetivos de aprendizaje
Git Básico:

Aprender los comandos esenciales de Git (git init, git add, git commit, git push, etc.).

Entender el flujo de trabajo básico (working directory, staging area, repositorio).

GitHub Básico:

Crear y gestionar repositorios.

Trabajar con ramas (branches) y fusiones (merges).

Colaborar mediante issues y pull requests.

GitHub Avanzado:

Explorar GitHub Actions para CI/CD.

Aprender a usar GitHub Pages para alojar proyectos web.

Entender cómo gestionar proyectos con GitHub Projects.
